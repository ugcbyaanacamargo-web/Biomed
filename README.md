# BIOMED — Sensibilidade Somática e Modulação da Dor

Site educacional interativo criado para estudo aprofundado de fisiologia sensorial.

## Conteúdo
- Sensibilidade somática e modalidades
- Receptores sensoriais
- Fibras Aβ, Aδ e C
- Vias ascendentes
- Nocicepção x dor
- Teoria do Portão
- Modulação descendente
- Atenção, emoção e contexto
- Semáforo Sensorial
- Aplicações clínicas
- Resumo de prova
- Flashcards, glossário e quiz

## Deploy no Netlify
1. Entre no Netlify.
2. **Add new site > Import an existing project**.
3. Conecte este repositório do GitHub.
4. Build command: deixe vazio.
5. Publish directory: `.`
6. Deploy.

O projeto é HTML/CSS/JS puro e não exige instalação ou build.

## Fontes
